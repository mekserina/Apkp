# OS-Foundry Kontrol Paneli - Android Project

Bu proje Web2APK Oluşturucu ile otomatik olarak üretilmiştir.

## Nasıl Derlenir (APK Oluşturulur)

1. **Android Studio**'yu indirin ve kurun.
2. Android Studio'da `File > Open` (Dosya > Aç) menüsüne gidin ve indirdiğiniz bu klasörü (arşivden çıkardıktan sonra) seçin.
3. Gradle'ın senkronize olmasını bekleyin.
4. Üst menüden `Build > Generate Signed Bundle / APK...` (Derle > İmzalı Bundle/APK Oluştur) seçeneğine tıklayın.
5. "APK" seçeneğini seçin ve ileri deyin.
6. Eğer bir Keystore'unuz yoksa yeni bir tane oluşturun, varsa seçin.
7. "Release" versiyonunu seçerek `Finish` butonuna tıklayın.
8. Birkaç dakika içinde uygulamanızın `.apk` dosyası projenin içindeki `app/release/` klasöründe oluşacaktır!
